# Governance

AI 에이전트 활용에 관한 권한·보안·감사 정책입니다.

## 1. 권한 모델

| 권한 등급 | 설명 | 예시 작업 | 승인자 |
|---|---|---|---|
| L0 — Read | 읽기 전용 | 코드·문서 조회 | 자동 |
| L1 — Local Write | 로컬 파일 수정 | 브랜치 내 코드 수정, 문서 작성 | Owner 자동 |
| L2 — Shared Write | 공유 자원 수정 | PR 생성, 이슈 코멘트 | Reviewer 1인 |
| L3 — Production | 운영 영향 | 배포, DB 마이그레이션, 외부 API 호출 | 사람 승인 필수 |
| L4 — Irreversible | 비가역 | 데이터 삭제, force-push, 외부 발송 | 사람 승인 + 2차 검토 |

## 2. 보안 정책

- 비밀(.env, credentials)을 산출물에 포함 금지
- 외부 LLM에 사내 데이터를 전달할 때는 데이터 분류 등급에 따른 마스킹 필수
- 에이전트가 실행한 모든 명령은 감사 로그에 남김

## 3. 데이터 분류

| 등급 | 정의 | 에이전트 처리 |
|---|---|---|
| Public | 외부 공개 가능 | 자유 |
| Internal | 사내 한정 | 사내 LLM 또는 승인된 외부 LLM |
| Confidential | 팀 한정 | 마스킹 후 처리, 결과 검토 필수 |
| Restricted | 개인정보·재무 | 에이전트 처리 금지 |

## 4. 감사

- 모든 Decision Log는 90일 이상 보존
- 분기별로 R&R 위반·에스컬레이션 통계를 집계해 회고에 반영

## 5. 사람 검토 의무 항목

다음은 반드시 사람이 검토·승인해야 한다.

- 운영 환경 배포
- 외부 커뮤니케이션(고객/파트너 발송)
- 법적 문서·계약 관련 산출물
- 보안 정책 변경
- 본 거버넌스 문서의 변경
