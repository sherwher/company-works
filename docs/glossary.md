# Glossary

| 용어 | 정의 |
|---|---|
| Agent | 특정 포지션의 R&R을 따라 작업을 수행하는 AI 실행 단위 |
| Charter | 프로젝트별 에이전트 활용 계약서. 활성 포지션·권한·DoD를 정의 |
| DoD (Definition of Done) | 산출물이 완료로 간주되기 위한 검증 가능한 기준 |
| Handoff | 작업 단위의 Owner가 다른 포지션으로 이전되는 행위 |
| R&R | Role & Responsibility — 포지션의 책임 범위와 행동 규약 |
| Work Unit | Goal·Inputs·Owner·Deliverables·Reviewers로 정규화된 최소 작업 단위 |
| Decision Log | 의사결정의 맥락·대안·선택을 남기는 기록 |
| Escalation | 에이전트가 사람에게 결정·검토를 요청하는 행위 |
| Reviewer | 산출물의 품질을 검증하고 승인 권한을 가진 포지션 |
| Owner | 작업 단위의 산출물에 책임을 지는 포지션 |
