# Synthesis — 핵심 원칙 및 설계 근거

본 문서는 리서치(01~03)에서 추출한 핵심 원칙을 통합한 것입니다. `CLAUDE.md` 템플릿의 직접적 설계 근거입니다.

## 한 줄 요약

> **각 포지션이 자기 에이전트를 갖되, 산출물 형식은 표준화하고, 핸드오프는 구조화하고, 위험 등급에 따라 사람 게이트를 건다.**

## 핵심 원칙 12가지

### A. 아키텍처

**1. 워크플로 우선, 에이전트는 마지막**
- 근거: Anthropic "워크플로로 충분한 일에 에이전트를 쓰지 마라", OpenAI "단일 에이전트 우선"
- 적용: 순차·분기·병렬로 풀 수 있으면 결정적 워크플로 사용. 자율 에이전트는 가치 > 비용일 때만.

**2. 한 포지션 = 한 에이전트 = 한 책임**
- 근거: MetaGPT, CrewAI, Anthropic MARS의 역할 분리 패턴
- 적용: PM, 기획, 디자이너, FE, BE, QA, DevOps 각각 자기 에이전트. 한 에이전트가 두 역할 금지.

**3. 명시적 작업 명세로 핸드오프**
- 근거: Anthropic MARS "모호한 위임이 중복·누락 주원인"
- 적용: 모든 핸드오프는 Goal·Inputs·Owner·Deliverables·DoD·Deadline 6슬롯 구조화.

### B. 산출물

**4. Draft-by-default + Citation**
- 근거: McKinsey Lilli, Anthropic 가이드. 모든 AI 산출물은 초안으로 시작.
- 적용: 메타데이터에 `generated_by`, `source_refs[]`, `status=draft|reviewed|approved` 강제.

**5. 3단계 승격 게이트**
- 근거: BCG Deckster, Anthropic MARS, 업계 공통 패턴
- 적용: AI 초안 → 동료/페어 리뷰 → 오너 승격(approved).

**6. 산출물 형식 표준화**
- 근거: MetaGPT의 구조화 산출물, OpenAI의 구조화 메시지 권고
- 적용: PRD, 기획서, Design Spec, API Contract, Test Plan 등 각 양식 고정.

### C. 검증

**7. 결정적 검사 → AI 리뷰 → 사람 리뷰**
- 근거: 환각을 LLM으로 잡으려 하지 말 것. 컴파일러·테스트·린터가 먼저.
- 적용: CI(코드) / 정책 룰(콘텐츠) / 스키마 검증(데이터) → LLM judge → 사람.

**8. Suggest, don't merge**
- 근거: GitHub Code Scanning Autofix, Snyk, 업계 수렴 방향
- 적용: 자동 머지·발행은 옵트인. 기본은 PR/Draft + 사람 명시 승인.

### D. 사람 게이트

**9. 위험 등급별 자율성 차등 (L0~L4)**
- 근거: OpenAI "비가역 작업은 사람 승인", 업계 동적 권한 아키텍처 수렴
- 적용: L0(읽기) / L1(개인 수정) / L2(공유 수정, 리뷰 필수) / L3(운영 영향, 승인) / L4(비가역, 이중 승인)

**10. 사람 호출은 항상 가능**
- 근거: Klarna 후퇴 핵심 교훈. 사람 핸드오프 경로 차단 → 브랜드 훼손.
- 적용: 어떤 단계에서든 사람 에스컬레이션 가능. 자동 요약 + 컨텍스트 전달.

### E. 운영

**11. 관측성 Day-1**
- 근거: Klarna가 후행 지표(CSAT)를 모니터링하지 못한 것이 후퇴 원인
- 적용: 모든 에이전트 호출 trace 저장. 비용·지연·품질 실시간 모니터링.

**12. Quality-adjusted 성과 측정**
- 근거: Klarna 단일 KPI(AI 처리율) 실패. "양적 효율성"만으론 부족.
- 적용: 효율(속도, 비용) + 품질(정확도, 완성도, 리뷰 통과율) + 만족도를 함께 측정.

## 안티패턴 8가지

| # | 하지 말 것 | 근거 |
|---|---|---|
| 1 | AI 처리율을 단독 KPI | Klarna CSAT 22%↓ |
| 2 | 사람 핸드오프 경로 차단 | Klarna 브랜드 훼손 |
| 3 | 자동 머지를 기본값 | 보안 취약점 유입 위험 |
| 4 | 모호한 에이전트 위임 | Anthropic MARS 초기 중복·누락 |
