# Workflow — Project Kickoff

새 프로젝트를 시작할 때의 표준 흐름.

## 단계

1. **Charter 작성** (Owner: PM + Tech Lead)
   - `agents/agent-charter-template.md` 복사
   - 활성 포지션·권한 등급·범위·일정 합의

2. **Discovery** (Owner: PM)
   - 사용자/시장/데이터 리서치 종합
   - 산출물: 문제 정의서, 가설 목록

3. **PRD 작성** (Owner: PM)
   - `templates/prd.md`
   - DoD: PRD 섹션 7 통과

4. **Design Spec** (Owner: Designer)
   - `templates/design-spec.md`
   - PRD AC 전부 커버

5. **Tech Spec / ADR** (Owner: Tech Lead)
   - `templates/tech-spec.md`
   - 핵심 결정은 ADR로 분리

6. **Plan & Estimate** (Owner: PM + TL)
   - 작업 단위(WU) 분해, 의존성 표기
   - 일정·우선순위 합의

## 진입 조건
- 비즈니스 목표 합의서 존재
- 결정자(승인자) 지정 완료

## 종료 조건
- PRD·Design Spec·Tech Spec 승인 완료
- 첫 스프린트 백로그 확정
