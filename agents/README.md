# Agents

본 디렉터리는 회사의 R&R을 따라 동작하는 AI 에이전트의 설정·운영 가이드를 제공합니다.

## 구성

- [`agent-charter-template.md`](./agent-charter-template.md) — 프로젝트별 에이전트 헌장 템플릿
- [`prompt-conventions.md`](./prompt-conventions.md) — 에이전트 시스템 프롬프트 작성 규약

## 에이전트 = 포지션

원칙: **한 에이전트는 한 포지션의 R&R만 수행**한다. 다중 포지션 수행이 필요하면 별도 에이전트를 분리하고 협업 규약을 따른다.

## 에이전트 부트스트랩 절차

1. 포지션의 R&R 문서(`rnr/<position>.md`)를 시스템 프롬프트로 주입
2. 협업 규약(`docs/collaboration-protocol.md`)을 컨텍스트로 추가
3. 거버넌스(`docs/governance.md`)의 권한 등급에 맞춰 도구 권한 제한
4. 프로젝트 헌장(Charter)을 컨텍스트로 주입
5. 산출물 템플릿(`templates/`)을 강제 양식으로 지정

## 운영 원칙

- **단일 책임**: 자신의 R&R 외 작업은 다른 에이전트로 위임/요청
- **출처 명시**: 모든 산출물은 입력·근거를 명시
- **에스컬레이션**: 비가역·범위 외·모호한 경우 즉시 사람에게 질문
- **검증 우선**: 추측보다 검증된 정보로 응답
