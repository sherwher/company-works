# Workflow: 기존 서비스 기능 추가

> 공통 규약은 [`../CLAUDE.md`](../CLAUDE.md). 포지션별 R&R/산출물은 [`../agents/`](../agents/).

## 흐름

```
요구사항 정리(PM) -> 기획서(기획) -> [Design Spec 필요시] -> 구현(FE/BE) -> 테스트(QA) -> 배포(DevOps)
```

- 신규 개발([full-cycle.md](./full-cycle.md))과 동일한 게이트 적용, 단 변경 범위에 따라 일부 게이트 생략 가능
- **차이점**: 기존 코드/디자인 시스템과의 일관성 검증 추가
- 영향도 분석(Impact Analysis)을 기획 단계에서 수행
- **AI 기능 추가/변경 시**: AI 엔지니어 합류. 기존 모델 대비 평가 회귀 검증 필수

## 게이트

| 게이트 | 통과 조건 |
|---|---|
| G1 | 요구사항 + 영향도 분석 완료 |
| G2 | 기획서에 기존 기능과의 충돌/호환성 명시 |
| G3~G7 | 신규 개발과 동일 |
