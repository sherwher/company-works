# Workflow: 마케팅 / 런칭 캠페인

> 공통 규약은 [`../CLAUDE.md`](../CLAUDE.md). 포지션별 R&R/산출물은 [`../agents/`](../agents/).

## 흐름

```
캠페인 브리프(PM) -> 콘텐츠 제작(에이전트 보조) -> 리뷰(관련 팀) -> 발행 -> 측정
```

- 콘텐츠 제작 시 에이전트가 변형(3개 이상) 생성 + 추천 1
- **발행은 항상 L3** (사람 승인 필수)
- 서비스 런칭 시점과 연동: QA Go 이후 캠페인 실행

## 캠페인 브리프 양식
공통 메타데이터([../shared/outputs.md](../shared/outputs.md)) + 다음 본문:

```
# Campaign - <name>
1. Goal / KPI
2. Audience / Persona
3. Channel
4. Tone & Brand Voice
5. 콘텐츠 변형 (3개 이상 + 추천 1)
6. 법적/정책 검토 사항
7. Measurement Plan
8. 일정
```

## 게이트

| 게이트 | 통과 조건 |
|---|---|
| G1 | 캠페인 브리프 완료: 목표/KPI/타겟/채널/톤 명시 |
| G2 | 콘텐츠 리뷰: 브랜드 보이스/법적 검토 통과 |
| G3 | 발행 승인: 사람 최종 승인 (L3) |
| G4 | 측정: 사후 메트릭 수집/분석 |
